# 🏛️ منظومة إدارة مكتب التوثيق العدلي — Cabinet Adoul Standalone

> **نظام متكامل، مستقل وقائم بذاته لتسيير مكاتب السادة العدول بالمملكة المغربية**  
> *Solution logicielle complète, autonome et installable dédiée à la gestion numérique d'une étude notariale adoulaire.*

---

## 🌟 نبذة عن المشروع | À propos

تم تطوير هذا النظام ليوفر حلاً رقمياً مستقلاً ومخصصاً لمكتب عدل فردي أو شراكة عدلية، بحيث يعمل المشروع بنطاقه الخاص (`votre-cabinet.ma`) وقاعدة بياناته المستقلة كلياً دون الحاجة للارتباط بمنصة مركزية أو منصة SaaS متعددة المشتركين.

يغطي النظام الدورة التوثيقية الكاملة ابتداءً من استقبال المواطن وتلقي الإشهاد وتدوينه بمذكرة الحفظ، مروراً بالاستخلاص والتحرير، وصولاً إلى التأشير القضائي (الخطاب) والتحقق بالرمز الشريطي والختم الرقمي المعتمد.

## 🚀 المميزات والوظائف الرئيسية | Fonctionnalités Clés

### 1. 🌐 البوابة العمومية للمكتب (Portail Citoyen)
* **واجهة المواطنين المخصصة:** تعرض بيانات المكتب، هيئة المحكمة الابتدائية التابع لها، أرقام التواصل، وأوقات العمل.
* **طلب المواعيد عن بعد:** تمكين المواطنين وأفراد الجالية (MRE) من طلب موعد مسبق للإشهاد أو الاستشارة.
* **طلب استخراج النظائر والنسخ:** نافذة لطلب نسخ من الرسوم القديمة مع تحديد طريقة الاستلام (حضورياً أو بريدياً).
* **تتبع مآل الملفات:** تتبع حي لمراحل إنجاز العقد (التلقي، الإذن القضائي، التسجيل والتنبر، خطاب قاضي التوثيق، جاهز للتسليم).
* **التحقق من صحة الوثائق (QR Verification):** مسح رمز الاستجابة السريعة للتحقق الفوري من صحة الرسوم وسلامة التأشير القضائي.
* **تخصيص الهوية البصرية:** إمكانية تغيير الألوان، الشعار، صورة الغلاف، ونبذة الأستاذ من لوحة التحكم.

### 2. 📁 إدارة ملفات التوثيق والمحررات (Dossiers & Actes)
* تغطية شاملة لكافة الرسوم والإشهادات الشرعية طبقاً للقانون 16.03 ومدونة الأسرة:
  * عقود الزواج، الطلاق، الرجعة، ثبوت الزوجية، الحضانة والنفقة، إقرار النسب.
  * المعاملات العقارية، البيوع، الهبات، الصدقة، الرهون الحيازية والرسمية، رفع اليد، الملكية واللفيف.
  * الوكالات الرسمية العامة والخاصة، الاعتراف بالدين، الوصايا، والشهادات الإدارية.
* مسار تدقيق شامل (**Audit Trail & Act Logs**) يرصد كل عملية وإجراء على الملف مع اسم المستخدم والتاريخ.
* **كناش التضمين ومذكرة الحفظ:** ترقيم وتدوين رسمي وفق مقتضيات المادة 24 من القانون المنظم.
* **بيان الأتعاب والرسوم القضائية:** حساب أتعاب العدول، رسوم التسجيل والتنبر (DGI)، ورسم صندوق التكافل العائلي تلقائياً.
* **طباعة العقود:** تصدير العقود ومحاضر التحرير بصيغة PDF وتضمين الرمز الشريطي والختم الرسمي.

### 3. ⚖️ حاسبة المواريث والفرائض الشرعية (Calculateur d'Héritage)
* حاسبة فقهية وقانونية متقدمة وفق قواعد المذهب المالكي ومدونة الأسرة المغربية.
* حصر الورثة، تحديد أصحاب الفروض والعصبات، تطبيق قواعد الحجب والنقصان، معالجة العول والرد.
* عرض شجرة الورثة التفصيلية ومقدار النصيب الشرعي وقيمته المالية بالدرهم المغربي.

### 4. 👥 سجل المرتفقين والزبناء (CRM Clients)
* قاعدة بيانات رقمية للأطراف والمتعاقدين مع أرقام بطاقات التعريف الوطنية (CIN) وتفاصيل الاتصال.
* الأرشيف التاريخي لكافة المعاملات والرسوم المرتبطة بكل طرف.

### 5. 📝 بنك النماذج ومسودات التحرير (Modèles & Word Parsing)
* نماذج قانونية جاهزة قابلة للتعديل مع دعم الحقول الذكية التلقائية (`{{husband_name}}`, `{{mahr_amount}}`, إلخ).
* إمكانية استيراد وقراءة مسودات العقود من ملفات Microsoft Word (`.docx`).

### 6. 🛡️ إدارة طاقم المكتب والصلاحيات (Équipe & Rôles)
* إدارة السادة العدول المشاركين بالمكتب، كتاب التوثيق، والمساعدين.
* تحديد دقيق للصلاحيات (التحرير، التوقيع، استعراض المداخيل المالية، الأرشفة).

## 🛠️ المتطلبات التقنية | Prérequis

- **PHP**: `^8.2` (مع إضافات: `pdo_mysql`, `mbstring`, `openssl`, `bcmath`, `curl`)
- **Composer**: `^2.2`
- **Node.js**: `^18.0` أو `^20.0` مع `npm`
- **قاعدة البيانات**: `MySQL 8.0+` أو `MariaDB 10.5+` (أو `SQLite`)
- **الخادم**: خادم محلي مثل `Laravel Herd`, `Laragon`, أو سيرفر إنتاجي `Nginx / Apache`

## 💻 طريقة التثبيت والتشغيل | Installation

### 1. استنساخ المشروع
```bash
git clone https://github.com/adol-saas/adoul-cabinet.git
cd adoul-cabinet
```

### 2. تثبيت الحزم والمكتبات
```bash
composer install
npm install
```

### 3. إعداد ملف البيئة
```bash
cp .env.example .env
php artisan key:generate
```

قم بفتح ملف `.env` وضبط إعدادات قاعدة البيانات الخاصة بمكتبك:
```env
APP_NAME="Cabinet Adoul"
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=adoul_cabinet
DB_USERNAME=root
DB_PASSWORD=
```

### 4. تهيئة قاعدة البيانات والبيانات الأولية
```bash
# إنشاء رابط التخزين للمستندات والشعارات
php artisan storage:link

# إنشاء الجداول وتوليد النماذج والمستخدم الافتراضي
php artisan migrate --seed
```

### 5. بناء الواجهة الأمامية
```bash
# للتطوير المباشر
npm run dev

# أو للبناء النهائي للإنتاج
npm run build
```

### 6. تشغيل الخادم
```bash
php artisan serve
```
افتح المتصفح على: `http://localhost:8000`

## 📂 بنية المجلدات الرئيسية | Structure du Projet

```text
adoul-cabinet/
├── app/
│   ├── Http/Controllers/
│   │   ├── Auth/                 # مصادقة طاقم المكتب
│   │   ├── Tenant/               # وحدات إدارة المكتب (Dossiers, Clients, Appointments...)
│   │   └── VerificationController.php # التحقق العمومي من صحة العقود
│   ├── Models/                   # نماذج البيانات (Dossier, Client, OfficeSetting...)
│   └── Services/                 # الخدمات المساعدة (MoroccanLegalTariffService...)
├── database/
│   ├── migrations/               # هيكل قاعدة بيانات المكتب
│   └── seeders/                  # النماذج الرسمية والمستخدمين المبدئيين
├── resources/
│   ├── js/
│   │   ├── components/           # عناصر الواجهة التفاعلية (Shadcn/UI & Radix)
│   │   ├── layouts/              # القالب الرئيسي للمكتب
│   │   └── pages/                # صفحات Inertia.js (المكتب، البوابة، الحسابات...)
│   └── views/                    # قالب Blade الأساسي (app.blade.php)
└── routes/
    └── web.php                   # المسارات المستقلة للمكتب
```
